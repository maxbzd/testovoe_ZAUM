# 0004. Анимации: CSS и View Transitions

## Контекст

Нужны живые, но не мешающие анимации. Библиотека анимаций добавила бы вес и сложность.

## Решение

- Появление, маркер видов, шторки, уведомления — CSS (`transform` и `opacity`, без перерасчёта раскладки).
- Перестроение строк при сортировке и фильтрах, смена темы — View Transitions API: браузер сам
  плавно «переезжает» между состояниями. Где API нет, обновление мгновенное.
- Числа в показателях считаются хуком на `requestAnimationFrame`.
- При `prefers-reduced-motion` анимации отключены целиком, числа показываются сразу.
- В шторке фильтров обновления мгновенные: список под шторкой закрыт, а переключатели должны отзываться без задержки
  (найдено в WebKit).

## Последствия

- Нет зависимостей для анимаций. Поведение в браузерах без View Transitions деградирует корректно.
