# 0003. Состояние экрана живёт в адресной строке

## Контекст

Менеджеры отправляют друг другу «посмотри этих блогеров на этапе согласования». Нужна ссылка на отбор.

## Решение

Запрос, статус, площадки, сортировка и открытая карточка хранятся в query-параметрах. Разбор строгий:
неизвестные значения отбрасываются, длина запроса ограничена. Запись идёт через `replaceState`
с задержкой 200 мс (Safari бросает ошибку после 100 вызовов за 30 секунд).

## Последствия

- Ссылкой можно поделиться, обновление страницы ничего не теряет.
- История браузера не засоряется: кнопка «назад» уводит с сервиса, а не по каждому фильтру.
- В песочницах без доступа к адресной строке состояние просто не сохраняется, это обработано.
