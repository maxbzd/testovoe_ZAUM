# 0001. Стек: Vite, React, TypeScript без UI-библиотек

## Контекст

Нужен небольшой сервис, который открывается по ссылке без установки и быстро грузится на телефоне.
Серверная часть не нужна: данные — снимок таблицы.

## Решение

Vite + React 19 + строгий TypeScript. Свои компоненты и CSS вместо UI-библиотеки. Иконки встроены в код,
шрифт Inter ставится пакетом и отдаётся с того же адреса.

## Последствия

- Бандл небольшой (JS около 86 КБ после gzip), внешних запросов нет, строгая CSP возможна.
- Таблица, шторки и палитра написаны вручную: больше кода, зато полный контроль над доступностью,
  анимациями и размером.
- React — основная часть веса. Замена на более лёгкую библиотеку дала бы выигрыш на медленных
  телефонах, но риск и стоимость пока не оправданы (Lighthouse на телефоне с замедлением: 95).
