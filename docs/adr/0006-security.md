# 0006. Безопасность: CSP, ссылки, CSV

## Контекст

Данные приходят из таблицы, то есть от людей. Хостинг (GitHub Pages) не позволяет задавать заголовки.

## Решение

- Строгая Content-Security-Policy в `<meta>`: только свои скрипты, стили и шрифты, без внешних запросов, форм и объектов.
  Для этого нет встроенных скриптов и атрибутов `style` (React ставит стили через CSSOM, это разрешено).
- Ссылки из данных проходят `safeExternalUrl`: только `http(s)`, открываются с `rel="noopener noreferrer"`.
- CSV экранирует ячейки, начинающиеся с `=`, `+`, `-`, `@`, чтобы Excel не выполнил их как формулы.
- Нет `dangerouslySetInnerHTML` и `innerHTML`.
- Зависимости: `npm audit`, проверка лицензий, Dependabot, действия CI закреплены по хешу, SBOM.

## Последствия

- Заголовки вроде `frame-ancestors` недоступны в `<meta>`; при переезде на хостинг с заголовками их стоит добавить.
