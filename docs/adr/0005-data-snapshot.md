# 0005. Данные: проверенный снимок таблицы

## Контекст

Исходник — Google-таблица. Прямое подключение требует ключей и сервера, а для прототипа это лишний риск.

## Решение

Выгрузка лежит в `data/bloggers.csv`. Скрипт `npm run data` разбирает её, строго проверяет (колонки, типы,
допустимые значения, формат даты, только `http(s)`-ссылки, уникальные номера) и пишет `src/data/bloggers.json`.
Тест следит, чтобы JSON всегда совпадал с CSV. Приложение проверяет данные ещё раз при запуске.

## Последствия

- Сломанная таблица даёт понятную ошибку при сборке, а не странности на экране.
- Данные не обновляются сами. Следующий шаг: Google Sheets API или периодическая выгрузка.
