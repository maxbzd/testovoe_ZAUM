# История изменений

Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии по смыслу изменений.

## [Без версии] — ноябрь 2026

### Добавлено

- Сервис по таблице блогеров: виды по статусам воронки, полоса показателей, таблица с сортировкой,
  карточка размещения, командная палитра ⌘K, экспорт в CSV, светлая и тёмная темы.
- Отдельная мобильная раскладка: лента показателей, закреплённые поиск и статусы, фильтры и сортировка
  одной шторкой, список в три строки, карточка шторкой.
- Состояние экрана в адресной строке, горячие клавиши (`/`, `⌘K`, `J`/`K`).
- Логотип ZAUM вектором.

### Качество

- Покрытие тестами 100% (операторы, ветки, функции, строки), порог проверяется в CI.
- Сквозные тесты в Chrome, Firefox и Safari (WebKit), проверка доступности axe, проверка ширин 320–1920.
- Строгие TypeScript и ESLint по типам, stylelint, хуки перед коммитом, бюджет размера, проверка лицензий, SBOM.
- Мутационные тесты (Stryker): 98–99% мутаций ловятся; тесты усилены по их результатам.
- Скриншотные тесты внешнего вида (опционально), записи о решениях (ADR), CONTRIBUTING.
- CSS разнесён по компонентам, `App` разделён на контроллер и две оболочки.
- Строгая CSP, проверка ссылок, защита CSV от формул.

### Исправлено

- Палитра поверх карточки перехватывает ввод и Esc (раньше буквы J/K листали карточку).
- Скрытая подпись таблицы расширяла страницу на 900–1024 пикселей.
- Переключатели в шторке фильтров отставали в Safari.
- Фокус при закрытии окон возвращается синхронно.
- Цвет панели браузера следует за выбранной темой; добавлен текст для отключённого JavaScript.
