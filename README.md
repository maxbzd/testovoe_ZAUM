# Размещения у блогеров

Рабочий сервис на основе таблицы блогеров: показывает, на каком этапе каждое размещение, сколько оно стоит и что дало, и помогает за пару секунд найти нужное. Все данные в демо вымышлены.

## Как запустить

```bash
npm install
npm run dev        # разработка: http://localhost:5173
npm test           # 50 тестов
npm run build      # продакшн-сборка в dist/
```

Другие команды: `npm run lint`, `npm run typecheck`, `npm run format`, `npm run data` (пересобрать данные из `data/bloggers.csv`), `npm run build:single` (один HTML-файл).

## Что внутри

**Первый экран** отвечает на вопросы, с которыми приходят каждый день:

- **Виды слева.** «Все» и по одному на каждый этап воронки (Согласование → Запланировано → Опубликовано → Результаты) со счётчиками. Счётчики учитывают поиск и фильтры.
- **Полоса показателей:** платный бюджет, бартер, охват сторис, средний CPM и сколько результатов уже получено. Всё пересчитывается под текущий отбор.
- **Плотная таблица** с сортировкой по любой колонке и тонкими индикаторами охвата.
- **Карточка размещения** открывается справа (на телефоне — шторкой снизу): воронка, результаты, затраты, аудитория, комментарий.

**Быстро найти нужное:**

- `/` — поиск по блогеру, артикулу, комментарию и остальным полям; все слова запроса должны встретиться.
- `⌘K` / `Ctrl+K` — палитра: прыгнуть к блогеру или выполнить действие (фильтр, экспорт, тема).
- `J` / `K` или стрелки — листать размещения в карточке, `Esc` — закрыть.
- Состояние (запрос, статус, площадка, сортировка, открытая карточка) хранится в адресной строке, ссылкой можно поделиться.

**Экспорт CSV** выгружает ровно то, что видно на экране (разделитель `;`, BOM — открывается в русском Excel).

## Решения по данным

- Бартер — это все размещения на YouTube, платные — Telegram и VK. Поэтому «Платный бюджет» считает только деньги, а бартер показан отдельно как оценка.
- Все колонки «Формат», «Возраст», «Гео» полностью определяются площадкой, поэтому отдельных фильтров по ним нет — достаточно фильтра по площадке.
- CPM считается по формуле таблицы (стоимость / охват сторис × 1000). В показателях он средневзвешенный.
- В «Затратах» итого = стоимость размещения + себестоимость товара.

## Дизайн и анимации

Направление «тихий инструмент»: плотный интерфейс, тонкие линии, почти монохром, цвет только у статусов. Светлая и тёмная темы (по умолчанию системная), кнопка в шапке переключает.

Анимации: каскадное появление, счётчики показателей, плавный маркер между видами, строки «переезжают» при сортировке и фильтрах (View Transitions API), выезд карточки, шторка со смахиванием, палитра, уведомления. При включённом в системе «уменьшить движение» всё сводится к мгновенному появлению.

## Безопасность и качество

- Строгая Content-Security-Policy (`default-src 'self'`, без inline-скриптов и внешних запросов), шрифт хостится локально.
- Ссылки из таблицы проходят проверку: только `http(s)`, открываются с `rel="noopener noreferrer"`.
- CSV защищён от формул (`=`, `+`, `-`, `@` в начале ячейки).
- Данные проверяются при сборке и при запуске: сломанная таблица даёт понятную ошибку.
- TypeScript в строгом режиме, ESLint, Prettier, 50 тестов (логика + сценарии интерфейса), `npm audit` в CI.
- Доступность: нативные кнопки и таблица, `aria-sort`, `aria-live`, фокус-ловушка в карточке, видимый фокус, цвет никогда не единственный носитель смысла.

## Структура

```
data/bloggers.csv          исходная выгрузка таблицы
scripts/build-data.mjs     CSV → проверенный JSON
src/lib/                   чистая логика: форматирование, метрики, фильтры, CSV, адрес
src/components/            интерфейс
src/styles/                токены тем, база, компоненты
```

## Что улучшить дальше

- Подключить таблицу напрямую (Google Sheets API или периодический экспорт) вместо снимка.
- Редактирование статусов и комментариев прямо в карточке с сохранением обратно в таблицу.
- Динамика во времени и сравнение блогеров по эффективности, когда накопится больше данных.
- Сохранённые виды (например, «Ждут результатов на этой неделе»).
