# Размещения у блогеров

Рабочий сервис на основе таблицы блогеров. Показывает, на каком этапе каждое размещение, сколько оно стоит и что дало, и помогает за пару секунд найти нужное. Одинаково удобен на компьютере и на телефоне. Все данные в демо вымышлены.

## Как запустить

```bash
npm install
npm run dev          # разработка: http://localhost:5173
npm run check        # форматирование, линтер, типы, тесты, сборка
npm run build        # продакшн-сборка в dist/
```

| Команда                      | Что делает                                                    |
| ---------------------------- | ------------------------------------------------------------- |
| `npm test`                   | Юнит-тесты и тесты интерфейса (Vitest, 63 теста)              |
| `npm run test:e2e`           | Сквозные тесты в браузере: сценарии, доступность, экраны      |
| `npm run lint` / `typecheck` | ESLint и строгий TypeScript                                   |
| `npm run format`             | Prettier                                                      |
| `npm run data`               | Пересобрать данные из `data/bloggers.csv`                     |
| `npm run build:single`       | Один HTML-файл без внешних зависимостей (для быстрого показа) |

Для e2e нужны браузеры: `npx playwright install chromium firefox webkit` (или `CHROME_PATH=/путь/к/chrome` для уже установленного Chromium).

## Что внутри

### Компьютер

- **Виды слева.** «Все» и по одному на каждый этап воронки (Согласование → Запланировано → Опубликовано → Результаты) со счётчиками. Счётчики учитывают поиск и фильтры. Выбранный вид подсвечивает один плавный маркер.
- **Полоса показателей:** платный бюджет, бартер, охват сторис, средний CPM, сколько результатов получено. Всё пересчитывается под текущий отбор.
- **Плотная таблица** с сортировкой по любой колонке и тонкими индикаторами охвата и просмотров.
- **Карточка размещения** справа: воронка, результаты, затраты, аудитория, комментарий. В ней можно листать клавишами.

### Телефон (до 900 пикселей)

Это отдельная раскладка, а не сжатая версия десктопа:

- **Лента показателей** вместо сетки: сверху сразу виден список, а не только цифры.
- **Закреплённая панель** поиска и статусов: при прокрутке всегда под рукой. Статусы одной горизонтальной лентой.
- **Фильтры и сортировка одной шторкой** (кнопка рядом с поиском). Показывает, сколько размещений будет в результате, и счётчик изменённых настроек на кнопке.
- **Строка списка в три линии:** кто и сколько стоит, где и когда, на каком этапе и что получили. Всё остальное в карточке.
- **Карточка шторкой снизу**, закрывается смахиванием вниз. Все нажимаемые элементы не меньше 44 пикселей, поля ввода 16 пикселей (iOS не увеличивает страницу при фокусе), учтены вырезы экрана.

### Быстрый поиск

- `/` — поиск по блогеру, артикулу, комментарию и остальным полям; все слова запроса должны встретиться.
- `⌘K` / `Ctrl+K` — палитра: прыгнуть к блогеру или выполнить действие (фильтр, экспорт, тема).
- `J` / `K` или стрелки — листать размещения в карточке, `Esc` — закрыть.
- Состояние (запрос, статус, площадка, сортировка, открытая карточка) хранится в адресной строке, ссылкой можно поделиться.

### Экспорт CSV

Выгружает ровно то, что видно на экране: разделитель `;`, BOM, десятичная запятая — открывается в русском Excel. Имя файла содержит дату.

## Решения по данным

- Бартер — это все размещения на YouTube, платные — Telegram и VK. Поэтому «Платный бюджет» считает только деньги, а бартер показан отдельно как оценка.
- Колонки «Формат», «Возраст» и «Гео» полностью определяются площадкой, поэтому отдельных фильтров по ним нет: хватает фильтра по площадке.
- CPM считается по формуле таблицы (стоимость / охват сторис × 1000). В показателях он средневзвешенный.
- «Итого» в затратах = стоимость размещения + себестоимость товара.

## Дизайн и анимации

Направление «тихий инструмент»: плотный интерфейс, тонкие линии, почти монохром, цвет только у статусов. Светлая и тёмная темы (по умолчанию системная), кнопка переключает. Логотип ZAUM встроен вектором и сам меняет цвет в тёмной теме.

Анимации: каскадное появление, разгон чисел, маркер между видами, строки «переезжают» при сортировке и фильтрах (View Transitions API), выезд карточки и шторок, палитра, уведомления. При включённом в системе «уменьшить движение» всё сводится к мгновенному появлению.

## Безопасность

- Строгая Content-Security-Policy: `default-src 'self'`, никаких встроенных скриптов, внешних запросов и форм. Шрифт хостится локально.
- Ссылки из таблицы проходят проверку: только `http(s)`, открываются с `rel="noopener noreferrer"`. Адреса вида `javascript:` и `data:` отбрасываются (есть тесты).
- CSV защищён от формул (`=`, `+`, `-`, `@` в начале ячейки).
- Данные проверяются при сборке и при запуске: сломанная таблица даёт понятную ошибку, а не пустой экран.
- Состояние из адресной строки разбирается строго: мусор игнорируется.
- Зависимости: `npm audit` в CI, Dependabot раз в неделю.

## Качество и скорость

- TypeScript в строгом режиме (включая `noUncheckedIndexedAccess`), ESLint, Prettier, `.editorconfig`.
- 86 юнит-тестов и тестов интерфейса (десктоп и телефон, покрытие строк около 95%) и сквозные e2e в Chrome, Firefox и Safari (WebKit, в том числе эмуляция iPhone): сценарии, проверка доступности axe в светлой и тёмной темах на главном экране, в карточке и палитре, отсутствие горизонтальной прокрутки на ширинах от 320 до 1920.
- Lighthouse (локальная сборка): десктоп 100 / 100 / 100 / 100; телефон с замедлением сети и процессора: производительность 95, доступность 100, лучшие практики 100, SEO 100.
- Доступность: нативные кнопки и таблица, `aria-sort`, `aria-live`, фокус-ловушка и возврат фокуса в окнах, видимый фокус, цвет никогда не единственный носитель смысла, контраст не ниже AA.
- Если интерфейс всё же упадёт, вместо белого экрана показывается сообщение с кнопкой «Обновить страницу».
- Современный CSS (`light-dark`, `color-mix`) приводится к совместимому виду через Lightning CSS по `browserslist` (Chrome и Firefox от 100, Safari и iOS от 15.4).
- Запись в адресную строку идёт с задержкой: Safari ограничивает `replaceState` сотней вызовов за 30 секунд.

## Структура

```
data/bloggers.csv          исходная выгрузка таблицы
scripts/build-data.mjs     CSV → проверенный JSON
src/lib/                   чистая логика: форматирование, метрики, фильтры, CSV, адрес
src/hooks/                 состояние адреса, расчёты, диалоги, шторки, горячие клавиши
src/components/            интерфейс (десктоп и телефон)
src/styles/                токены тем, база, компоненты
e2e/                       сквозные тесты и проверки доступности
```

## Что улучшить дальше

- Подключить таблицу напрямую (Google Sheets API или периодический экспорт) вместо снимка.
- Редактирование статусов и комментариев в карточке с сохранением обратно в таблицу.
- Динамика во времени и сравнение блогеров по эффективности, когда накопится больше данных.
- Сохранённые виды (например, «Ждут результатов на этой неделе») и PWA для установки на телефон.
